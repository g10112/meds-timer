# Install or update Meds Timer

**Android 14 or newer. Free. No accounts, ads or internet connection needed by the app.**

## Direct download

1. Open [the latest official release](https://github.com/g10112/meds-timer/releases/latest).
2. Download **MedsTimer.apk** and open it.
3. Allow the phone to install it when prompted. Open Meds Timer and complete its alarm permissions.
4. Keep using the same official download page for future updates. You do not need to uninstall first.

## Automatic update checks with Obtainium

Obtainium is a separate, open-source Android app that watches GitHub release pages.

1. Install [Obtainium](https://obtainium.imranr.dev/).
2. Choose **Add App** and paste `https://github.com/g10112/meds-timer`.
3. Add the app, then install **MedsTimer.apk** from its official release.
4. Obtainium can notify you when the maintainer publishes another signed APK.

**Already using the official Meds Timer APK?** You can add it to Obtainium without uninstalling, provided the APK is signed with the same release certificate.

**Do not mix app stores:** an F-Droid-signed build could have a different signature and might not update an existing GitHub installation. Use the same source for future updates unless you are prepared to migrate.

The earlier **debug/preview** app is a separate Android installation. Cancel its old alarms and uninstall that preview to prevent duplicate alerts.

**Safety:** This is a reminder utility, not a dose tracker. Check your own prescribed schedule and keep a backup alert for time-critical medicines.
