# Meds Timer — public announcement

**Meds Timer is now available for Android.**

I made a simple, free medication reminder app. You set three reminder times, tap Start, and it alerts you when they are due.

It works offline, has home-screen widgets and adjustable alarm sounds, and there are no adverts, accounts, subscriptions or tracking. The source code is public under GPL-3.0-or-later.

Download: https://github.com/g10112/meds-timer/releases/latest

Source and help: https://github.com/g10112/meds-timer

Android 14 or newer. Meds Timer is a reminder, not a medical device or dose tracker. Please follow your prescribed schedule and use a backup reminder for critical doses.
